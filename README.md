# esp32-low-power-weather-station
Simple weather station built with esp32, BME280 and Oled display, featuring deep sleep power optimalization

Key features:

-Real time readings every 150 seconds from BME280(Temperature, humidity, pressure)

-Data is shown on OLED display connected to esp32

-Optimization for low power consumption using forced measurment and esp32 deep sleep.

Hardware:

-ESP32 DevKit

-Bosch BME280 (I2C)

-1.3" OLED SH1106 (128x64, I2C)

Language: C++ (Arduino IDE)
